# Bandit Уровень 25 → 26

## Задача
Использовать SSH-ключ для входа на bandit26, обойти ограничения оболочки (more/vim) и получить пароль.

## Что я сделал
1. Нашёл файл `bandit26.sshkey` на уровне 25
2. Скопировал ключ на локальную машину
3. Подключился с ключом: `ssh -i bandit26.sshkey bandit26@localhost -p 2220`
4. Уменьшил окно терминала, чтобы `more` перешёл в интерактивный режим
5. Нажал `v` для запуска `vim`
6. В `vim` выполнил `:!/bin/bash`
7. Получил командную оболочку и прочитал пароль

## Команды, которые изучил
- Использование SSH-ключа для входа
- Обход `more` через изменение размера окна
- `vim` — `:!/bin/bash` для запуска оболочки
