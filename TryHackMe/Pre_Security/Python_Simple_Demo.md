# TryHackMe: Python Simple Demo

## 📌 Краткое описание
Пройден модуль, посвящённый основам программирования на Python. На практике разобрана программа «Угадай число», включающая работу с переменными, условными операторами и циклами. Изучены базовые функции ввода-вывода и генерации случайных чисел. Понимание этих концепций критично для написания скриптов автоматизации, анализа данных и разработки инструментов безопасности.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Переменные и типы данных
- **Создание и использование переменных:** `secret`, `tries`, `guess`.
- **Преобразование типов:** `int()` для преобразования строки в число.
- **Хранение состояния:** счётчик попыток (`tries`).

### 2. Условные операторы (if / elif / else)
- **Синтаксис:** `if`, `elif`, `else`.
- **Операторы сравнения:** `<`, `>`, `!=`, `==`, `<=`, `>=`.
- **Логические операторы:** `and`, `or`, `not`.
- **Применение:** проверка условий, ветвление логики.

### 3. Циклы (while)
- **Синтаксис:** `while condition:`
- **Логика:** повторение блока кода, пока условие истинно.
- **Применение:** игра продолжается, пока пользователь не угадает число.

### 4. Базовые функции Python
| Функция | Назначение | Пример |
| :--- | :--- | :--- |
| **`print()`** | Вывод текста на экран. | `print("Hello")` |

| **`random.randint()`** | Генерация случайного числа. | `random.randint(1, 20)` |
