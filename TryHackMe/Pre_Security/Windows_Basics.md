# TryHackMe: Windows Basics

## 📌 Краткое описание
Пройден модуль, посвящённый основам операционной системы Windows. Изучены ключевые компоненты интерфейса, управление приложениями и файловой системой, а также встроенные механизмы безопасности. Понимание Windows критично для работы в среде, которая является основной целевой платформой для большинства корпоративных пользователей и атакующих.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание интерфейса и навигации
- **Рабочий стол, Панель задач, Меню «Пуск»:** Уверенная навигация в среде Windows.
- **Проводник файлов:** Управление файлами и папками.
- **Поиск:** Быстрый доступ к приложениям и настройкам.

### 2. Управление системой и приложениями
- **Настройки Windows:** Централизованное управление системой, устройствами, персонализацией.
- **Панель управления:** Доступ к классическим настройкам системы.
- **Диспетчер задач:** Мониторинг процессов, производительности и запущенных приложений.
- **Microsoft Store:** Установка приложений.

### 3. Безопасность Windows
| Компонент | Что делает | Почему важно для безопасности |
| :--- | :--- | :--- |
| **Windows Security** | Центральная панель управления защитой. | Управление антивирусом, брандмауэром, защитой от угроз. |
| **Windows Defender Файрвол** | Фильтрация сетевого трафика. | Блокирует подозрительные входящие и исходящие соединения. |
| **Windows Update** | Автоматическое обновление системы. | Закрывает уязвимости, которые могут быть использованы злоумышленниками. |
| **Диспетчер задач** | Просмотр запущенных процессов. | Помогает выявлять вредоносные или подозрительные процессы. |

### 4. Практический опыт
- Работал с Windows Server 2019 в лабораторной среде TryHackMe.
- Изучал файловую систему, устанавливал приложения.
- Проводил базовое сканирование безопасности рабочей станции.

## 🔗 Связь с реальной работой
- Понимаю, как ориентироваться и управлять системой Windows.
- Знаю, как использовать встроенные инструменты безопасности (Windows Security, Defender Firewall).
- Могу мониторить систему через Диспетчер задач для выявления аномалий.
