# TryHackMe: Linux Fundamentals Part 1

## 🎯 Цель комнаты
Познакомиться с основами Linux: историей, базовыми командами, навигацией, поиском файлов и операторами оболочки.

## 🛠️ Что я научился делать

### Базовые команды
- `echo` — вывод текста в терминал
- `whoami` — узнать имя текущего пользователя
- `ls` — просмотр содержимого папки (`-la` для скрытых файлов)
- `cd` — навигация по файловой системе
- `pwd` — показать текущую рабочую папку
- `cat` — чтение содержимого файлов

### Поиск файлов
- `find / -name "*.txt"` — поиск файлов по имени
- `grep "password" file.txt` — поиск текста внутри файлов

### Операторы оболочки
- `&` — запуск команды в фоне
- `&&` — выполнить следующую команду только если предыдущая успешна
- `>` — перенаправить вывод в файл (перезапись)
- `>>` — добавить вывод в конец файла
