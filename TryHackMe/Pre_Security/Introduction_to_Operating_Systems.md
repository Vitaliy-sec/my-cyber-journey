# TryHackMe: Introduction to Operating Systems

## 📌 Краткое описание
Пройден модуль, посвящённый основам операционных систем: их структуре, компонентам и принципам работы. Изучены различия между пространством ядра и пользовательским пространством, механизмы управления процессами, памятью и пользователями. Понимание ОС критично для анализа уязвимостей, управления доступом и обеспечения безопасности систем.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание структуры ОС
- **Операционная система (ОС):** Управляет аппаратным обеспечением, приложениями и ресурсами.
- **Ядро (Kernel):** Высокопривилегированная часть с прямым доступом к аппаратному обеспечению.
- **Пространство пользователя (User Space):** Приложения с ограниченными правами.

### 2. Управление ресурсами
- **Управление процессами:** Создание, планирование, завершение процессов.
- **Управление памятью:** Распределение оперативной памяти между приложениями.
- **Управление файловой системой:** Организация хранения данных.
- **Управление пользователями:** Права доступа и аутентификация.

### 3. Понимание интерфейсов
- **GUI (Graphical User Interface):** Визуальный интерфейс для взаимодействия с системой.
- **CLI (Command Line Interface):** Текстовый интерфейс для точного управления системой.

### 4. Связь с безопасностью (практическое применение)
| Компонент | Что делает | Почему важно для безопасности |
| :--- | :--- | :--- |
| **Ядро (Kernel)** | Управляет аппаратным обеспечением. | Любая уязвимость в ядре — критична. |
| **Пространство пользователя** | Изолирует приложения от ядра. | Защищает систему от нестабильных приложений. |
| **Управление процессами** | Контролирует выполнение программ. | Позволяет выявлять вредоносные процессы. |
| **Управление памятью** | Распределяет RAM. | Неправильное управление → уязвимости. |
| **Управление пользователями** | Определяет права доступа. | Основа безопасности и ограничения прав. |
