# TryHackMe: Defensive Security Intro (Оборонительная безопасность)

## 📌 Краткое описание
Пройден модуль, посвящённый основам оборонительной безопасности (Blue Team). Изучены принципы защиты инфраструктуры, важность видимости активов и концепция «мышления защитника». На практике выполнено картографирование инфраструктуры (Asset Inventory) и применение многоуровневых мер защиты.

## 🛠️ Ключевые навыки и знания

### 1. Оборонительная безопасность
- **Prevention (Профилактика):** Внедрение мер для предотвращения атак (файрволы, антивирусы, патчи).
- **Detection (Обнаружение):** Мониторинг систем и логов для выявления подозрительной активности.
- **Mitigation (Смягчение):** Ограничение ущерба во время инцидента (блокировка IP, изоляция систем).
- **Analysis (Анализ):** Расследование инцидентов и понимание, что произошло.
- **Risk Prioritization (Приоритизация рисков):** Выявление наиболее важных систем и целей.

### 2. Мышление защитника (Defender Mindset)
- **Ожидание угроз:** Вопрос «Что может пойти не так?» для каждого компонента системы.
- **Осознанность атаки:** Понимание этапов атаки (например, фишинг -> кража учетных данных -> доступ к БД).
- **Многоуровневая защита:** Использование разных инструментов для разных систем (антивирус для сотрудников, правила для файрвола, спам-фильтры для почты).

### 3. Картографирование инфраструктуры
- Понимание того, какие активы необходимо защищать (устройства сотрудников, веб-серверы, почтовые серверы, файрволы).
- Осознание того, что каждый элемент имеет свою ценность и уязвимости.
