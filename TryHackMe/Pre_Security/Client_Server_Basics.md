# TryHackMe: Client-Server Basics

## 📌 Краткое описание
Пройден модуль, посвящённый клиент-серверной архитектуре и протоколу HTTP. Изучены принципы взаимодействия клиента и сервера, структура HTTP-запросов и ответов, методы и механизмы поддержания состояния (сессии, cookies). Понимание этих основ критично для анализа веб-трафика, выявления уязвимостей и защиты веб-приложений.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание клиент-серверной модели
- **Клиент:** Инициирует запрос (браузер, мобильное приложение).
- **Сервер:** Обрабатывает запрос и возвращает ответ.
- **Взаимодействие:** Модель «запрос-ответ», лежащая в основе интернета.

### 2. HTTP-протокол
- **Безсостоятельность:** Понимаю, что каждый запрос обрабатывается независимо.
- **Механизмы состояния:** Знаю, как cookies и сессии сохраняют пользовательский контекст.
- **Методы:** GET, POST, PUT, DELETE, PATCH.
- **Заголовки:** Host, User-Agent, Content-Type, Cookie, Set-Cookie.

### 3. Анализ HTTP-трафика
- **Инструменты:** Использовал DevTools (Network) для анализа запросов и ответов.
- **Что проверял:** Заголовки, параметры, cookie, статус-коды.

## 🧠 Связь с безопасностью (практическое применение)

| Угроза | Как злоумышленник использует | Как защититься |
| :--- | :--- | :--- |
| **Угон сессии** | Перехват cookie → доступ к аккаунту. | HTTPS, Secure-флаг, HttpOnly-флаг. |
| **CSRF** | Подделка запроса от имени пользователя. | CSRF-токены, SameSite-флаги. |
| **XSS** | Внедрение скрипта для кражи cookie. | Экранирование ввода, CSP. |
| **SQL-инъекции** | Внедрение кода в запрос к БД. | Параметризованные запросы. |
