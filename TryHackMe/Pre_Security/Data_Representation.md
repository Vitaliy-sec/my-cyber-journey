# TryHackMe: Data Representation

## 📌 Краткое описание
Пройден модуль, посвящённый основам представления данных в компьютерных системах. Изучены системы счисления (двоичная, восьмеричная, десятичная, шестнадцатеричная), понятия бита и байта, а также принципы кодирования цветов (Hex). Понимание этих концепций критично для анализа низкоуровневых данных, отладки и работы с бинарными файлами.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание систем счисления
| Система | Основание | Применение в ИБ |
| :--- | :--- | :--- |
| **Двоичная (Binary)** | 2 | Работа с бинарными файлами, анализ трафика, маски подсетей. |
| **Восьмеричная (Octal)** | 8 | Права доступа в Linux (`chmod 755`). |
| **Шестнадцатеричная (Hex)** | 16 | Анализ дампов памяти, HEX-редакторы, цвета в вебе. |
| **Десятичная (Decimal)** | 10 | Повседневное использование. |

### 2. Базовые понятия
- **Бит (Bit):** Минимальная единица данных (0 или 1). Основа всей цифровой информации.
- **Байт (Byte):** 8 бит. Стандартная единица хранения данных.
- **Hex Color:** Представление цвета в формате `#RRGGBB` (красный, зелёный, синий). Используется в веб-разработке и анализе.

### 3. Связь с безопасностью (практическое применение)
| Концепция | Как используется в ИБ | Пример |
| :--- | :--- | :--- |
| **Двоичная система** | Анализ бинарных файлов, работа с масками подсети. | `chmod 755` → права на выполнение. |
| **Шестнадцатеричная система** | Анализ дампов памяти, HEX-редакторы. | Поиск сигнатур в бинарных файлах. |
| **Hex Color** | Взлом веб-приложений через анализ CSS. | Поиск скрытых данных в изображениях. |
| **Байт** | Понимание объёма данных, утечек. | Анализ размера передаваемых данных. |

## 🧠 Примеры из практики
- Преобразовывал десятичные числа в двоичные, восьмеричные и шестнадцатеричные.
- Анализировал права доступа в Linux через восьмеричные значения (`755`, `644`).
- Интерпретировал цвета в формате `#RRGGBB` для анализа веб-страниц.
