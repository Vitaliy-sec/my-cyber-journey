# TryHackMe: Inside a Computer System

## 📌 Краткое описание
Пройден модуль, посвящённый аппаратному обеспечению компьютера, процессу загрузки и связанным с ними угрозам безопасности. Понимание работы компонентов системы и процесса загрузки критично для анализа и предотвращения атак на низком уровне (bootkits, rootkits, UEFI-атаки).

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Аппаратное обеспечение (Hardware)
- **CPU:** Понимаю архитектуру процессора, выполнение инструкций и роль в обработке данных.
- **RAM:** Знаю разницу между оперативной памятью и постоянным хранилищем.
- **Storage:** Понимаю разницу между HDD, SSD и NVMe, а также их влияние на производительность и безопасность.
- **Motherboard:** Знаю, как компоненты взаимодействуют через шины (PCIe, SATA).
- **PSU:** Понимаю основы питания и энергопотребления.

### 2. Процесс загрузки (Boot Process)
- **BIOS/UEFI:** Понимаю роль прошивки в инициализации оборудования (POST) и запуске загрузчика.
- **Bootloader:** Знаю, как загрузчик передаёт управление операционной системе.
- **OS Kernel:** Понимаю, как ядро управляет аппаратными ресурсами.

### 3. Угрозы на уровне системы (Security)
- **Bootkits:** Понимаю, как вредоносное ПО может заражать процесс загрузки (MBR, UEFI). Знаю, что такие угрозы могут пережить переустановку ОС.
- **Rootkits:** Понимаю, как руткиты внедряются в ядро ОС или приложения, маскируя своё присутствие.
- **Атаки на BIOS/UEFI:** Знаю об угрозах на уровне прошивки материнской платы (например, LoJax, MosaicRegressor). Понимаю важность Secure Boot и TPM.
- **Аппаратные уязвимости:** Знаю о Spectre, Meltdown и их влиянии на безопасность.

### 4. Практическое применение
- **Анализ угроз:** Могу оценивать риски, связанные с атаками на процесс загрузки.
- **Защита:** Понимаю, как использовать Secure Boot, TPM и обновления прошивки для защиты системы.
- **Диагностика:** Умею обнаруживать признаки руткитов (необычные загрузки, скрытые процессы).

## 🧠 Примеры из практики
- Изучал случай буткита BootKitty для Linux и принципы его работы.
- Анализировал уязвимость LogoFAIL (CVE-2023-40238) и её влияние на безопасность загрузки.
- Настраивал Secure Boot и TPM для защиты от низкоуровневых атак.
