# TryHackMe: Putting It All Together (Web Infrastructure)

## 📌 Краткое описание
Пройден модуль, посвящённый архитектуре веб-инфраструктуры. Изучены ключевые компоненты, обеспечивающие работу современных высоконагруженных веб-приложений: балансировщики нагрузки, CDN, базы данных и WAF. Понимание этих компонентов и их взаимодействия критично для анализа архитектуры, выявления точек отказа и обеспечения безопасности на уровне инфраструктуры.

## 🛠️ Ключевые навыки и знания

### 1. Балансировщики нагрузки (Load Balancers)
- **Что делают:** Распределяют входящий трафик между несколькими серверами, предотвращая перегрузку.
- **Функции:** 
  - Распределение нагрузки (round-robin, взвешенный алгоритм).
  - Резервное переключение (failover) — если сервер не отвечает, трафик идёт на другой.
  - Медицинский осмотр (health check) — периодическая проверка работоспособности серверов.
- **Связь с ИБ:** Являются критической точкой инфраструктуры. При компрометации балансировщика под угрозой оказываются все серверы за ним.

### 2. CDN (Content Delivery Network)
- **Что делает:** Хранит статические файлы (JS, CSS, изображения, видео) и отдаёт их пользователю с ближайшего географического сервера.
- **Связь с ИБ:** Может быть использован для распространения вредоносного контента. Требует настройки безопасности (HTTPS, целостность файлов).

### 3. Базы данных (Databases)
- **Что делает:** Хранит и обрабатывает информацию (пользователи, заказы, логи).
- **Типы:** Реляционные (MySQL, PostgreSQL, MSSQL) и NoSQL (MongoDB).
- **Связь с ИБ:** Главная цель для атак (SQL-инъекции, кража данных). Требует строгого контроля доступа и шифрования.

### 4. WAF (Web Application Firewall)
- **Что делает:** Стоит между пользователем и веб-сервером. Анализирует входящие запросы и блокирует подозрительные.
- **Функции:**
  - Фильтрация атак (XSS, SQL-инъекции).
  - Ограничение скорости (rate limiting) для защиты от DDoS.
  - Отсеивание ботов.
- **Связь с ИБ:** Первая линия защиты веб-приложений. Может быть обойдён, поэтому требует постоянного обновления правил.

## 🧠 Практическое применение для безопасности
| Компонент | Угроза | Мера защиты |
| :--- | :--- | :--- |
| **Балансировщик** | Единая точка отказа, DDoS. | Резервирование, rate limiting. |
| **CDN** | Распространение вредоносного контента. | Проверка целостности, HTTPS. |
| **База данных** | SQL-инъекции, утечки. | Параметризованные запросы, шифрование. |
| **WAF** | Обход фильтрации, ложные срабатывания. | Регулярное обновление правил. |
