# TryHackMe: Cloud Computing Fundamentals

## 📌 Краткое описание
Пройден модуль, посвящённый основам облачных вычислений: моделям развёртывания (публичное, частное, гибридное облако), моделям сервисов (IaaS, PaaS, SaaS) и ключевым преимуществам для бизнеса. Понимание этих концепций критично для работы с современными инфраструктурами, проектирования безопасных и масштабируемых систем.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание моделей развёртывания

| Модель | Описание | Когда используется |
| :--- | :--- | :--- |
| **Публичное облако** | Сервисы через интернет, доступные всем. | Стартапы, разработка, проекты с переменной нагрузкой. |
| **Частное облако** | Облако для одной компании (выше контроль и безопасность). | Крупные корпорации, финансовый сектор, госорганы. |
| **Гибридное облако** | Комбинация публичного и частного. | Компании, которым нужна гибкость и безопасность. |

### 2. Понимание моделей сервисов (IaaS, PaaS, SaaS)

| Модель | Что предоставляет | Примеры | Ключевое преимущество |
| :--- | :--- | :--- | :--- |
| **IaaS** | Базовые ресурсы (серверы, хранилище, сети). | AWS EC2, Google Compute Engine | Полный контроль над инфраструктурой. |
| **PaaS** | Платформа для разработки и развертывания. | Google App Engine, Heroku | Не нужно управлять серверами, фокус на код. |
| **SaaS** | Готовое ПО через интернет. | Gmail, Zoom, Google Docs | Не нужно устанавливать, обновлять, поддерживать. |

### 3. Ключевые преимущества облачных вычислений

- **Масштабируемость:** Ресурсы растут с потребностями бизнеса.
- **Плати за использование:** Оплата только за потреблённые ресурсы.
- **Высокая доступность:** 24/7 доступность сервисов.
- **Безопасность:** Встроенные механизмы защиты (IAM, шифрование).
- **Глобальный доступ:** Доступ из любой точки мира.

### 4. Связь с безопасностью (практическое применение)

| Аспект | Возможности для безопасности | Риски |
| :--- | :--- | :--- |
| **IaaS** | Настройка собственных политик безопасности, контроль доступа. | Необходимость правильно настраивать защиту (ответственность на клиенте). |
| **PaaS** | Встроенные механизмы аутентификации и авторизации. | Ограниченный контроль над инфраструктурой. |
| **SaaS** | Провайдер управляет безопасностью (включая шифрование, обновления). | Зависимость от политик безопасности провайдера. |
| **Гибридное облако** | Гибкость в размещении чувствительных данных. | Сложность управления единой политикой безопасности. |
