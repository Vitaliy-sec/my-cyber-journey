# TryHackMe: Windows Command Line

## 📌 Краткое описание
Пройден модуль, посвящённый работе с командной строкой Windows (CMD). Изучены ключевые команды для навигации по файловой системе, поиска файлов, сбора системной информации и анализа состояния сети. Эти навыки критичны для быстрой диагностики, расследования инцидентов и автоматизации задач в среде Windows.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Навигация по файловой системе (без GUI)
- **`cd`** — перемещение по директориям.
- **`dir`** — просмотр содержимого каталогов.
- **`tree`** — визуализация структуры папок.
- Уверенное перемещение в среде без графического интерфейса.

### 2. Поиск файлов
- **`dir /s`** — рекурсивный поиск по каталогам.
- **`findstr`** — поиск текста внутри файлов.
- Обнаружение скрытых файлов и каталогов (`dir /a`).

### 3. Чтение файлов из терминала
- **`type`** — просмотр содержимого файлов.
- **`more`** — постраничный просмотр больших файлов.
- Быстрый доступ к логам и конфигурационным файлам.

### 4. Сбор системной и сетевой информации
| Команда | Что показывает |
| :--- | :--- |
| **`systeminfo`** | Подробная информация об ОС, железе, обновлениях. |
| **`tasklist`** | Список запущенных процессов. |
| **`ipconfig`** | Настройки сетевых адаптеров. |
| **`netstat`** | Активные сетевые соединения и открытые порты. |

### 5. Связь с безопасностью (практическое применение)
| Навык | Как используется в безопасности | Пример |
| :--- | :--- | :--- |
| **Навигация** | Быстрое перемещение по системе для проверки подозрительных папок. | `cd C:\Users\Public\` → проверка на скрытые файлы. |
| **Поиск файлов** | Выявление скрытых или недавно изменённых файлов. | `dir /s /a *.exe` → поиск всех EXE-файлов в системе. |
| **Чтение файлов** | Анализ логов безопасности и конфигураций. | `type C:\Windows\System32\drivers\etc\hosts` → проверка на подмену. |
| **Системная информация** | Выявление аномалий в процессах и сети. | `netstat -ano` → поиск подозрительных соединений. |
