# TryHackMe: Offensive Security Intro (Практика взлома / Brute-Force)

## 📌 Краткое описание
Продолжение практики по наступательной безопасности. Изучена концепция «цепочки уязвимостей» (Weakness Chaining). На практике выполнена атака перебором паролей (Brute-Force) на форму авторизации. Применён инструмент **Hydra** для автоматизации подбора пароля по словарю.

## 🧠 Ключевые концепции
- **Цепочка уязвимостей (Weakness Chaining):** Комбинирование мелких недостатков (например, открытая страница входа + слабый пароль) для получения доступа.
- **Думай как хакер:** Умение задавать вопрос «А что, если?» и тестировать неожиданные сценарии.
- **Ценная цель:** Понимание, что злоумышленник ищет учетные данные (логин/пароль) для доступа к функциям, данным и административным панелям.

## 🛠️ Практические навыки
- **Ручной подбор пароля:** Проверка типовых паролей (admin, 123456, qwerty).
- **Автоматизированный подбор (Словарная атака):** Использование `hydra` для перебора паролей из словаря (`passlist.txt`).
