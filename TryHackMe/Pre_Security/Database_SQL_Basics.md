# TryHackMe: Database SQL Basics

## 📌 Краткое описание
Пройден модуль, посвящённый основам баз данных и языку SQL. Изучены структура реляционных баз данных (таблицы, строки, столбцы), основные команды для выборки, фильтрации и сортировки данных. Понимание SQL критично для анализа данных, работы с логами и выявления уязвимостей (SQL-инъекции).

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание баз данных
- **Таблицы:** Набор связанных данных.
- **Строки:** Отдельные записи (например, один заказ).
- **Столбцы:** Характеристики записи (id, drink, price, time).
- **Реляционная модель:** Связи между таблицами.

### 2. Основные команды SQL
| Команда | Назначение | Пример |
| :--- | :--- | :--- |
| **SELECT** | Выбор столбцов для отображения. | `SELECT * FROM Orders;` |
| **FROM** | Указание таблицы-источника. | `FROM Orders` |
| **WHERE** | Фильтрация записей по условию. | `WHERE drink = 'Coffee'` |
| **ORDER BY** | Сортировка результатов. | `ORDER BY price DESC` |

### 3. Практические примеры
```sql
-- Показать все заказы
SELECT * FROM Orders;

-- Показать только напитки и цены
SELECT drink, price FROM Orders;

-- Показать только кофе
SELECT * FROM Orders WHERE drink = 'Coffee';

-- Сортировать по цене (по возрастанию)
SELECT * FROM Orders ORDER BY price;

-- Сортировка по цене (по убыванию)
SELECT * FROM Orders ORDER BY price DESC;

-- Комбинация: фильтр + сортировка
SELECT * FROM Orders WHERE drink = 'Coffee' ORDER BY price DESC;
