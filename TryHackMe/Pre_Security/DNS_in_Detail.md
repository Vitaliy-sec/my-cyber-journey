# TryHackMe: DNS in Detail

## 📌 Краткое описание
Пройден модуль, посвящённый системе доменных имён (DNS). Изучена архитектура DNS, типы записей, процесс разрешения доменных имён и связанные с ними угрозы безопасности. Понимание DNS критично для анализа веб-трафика, выявления фишинговых атак и настройки безопасной инфраструктуры.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Архитектура и процесс DNS
- **DNS-запрос (Recursive/Iterative):** Понимаю полный путь DNS-запроса от браузера до авторитетного сервера.
- **Роли серверов:** Знаю разницу между рекурсивным, корневым, TLD и авторитетным DNS-серверами.
- **Кэширование и TTL:** Понимаю, как работает кэширование DNS и как TTL влияет на доступность сервисов.

### 2. DNS-записи (типы и применение)
| Тип записи | Назначение | Пример использования в работе |
| :--- | :--- | :--- |
| **A** | IPv4-адрес | Связывание домена с IP-адресом сервера. |
| **AAAA** | IPv6-адрес | Поддержка современных IPv6-сетей. |
| **CNAME** | Псевдоним (алиас) | Упрощение управления поддоменами. |
| **MX** | Почтовый сервер | Настройка почтовой инфраструктуры. |
| **TXT** | Текстовая информация | SPF, DKIM, DMARC для защиты от спама. |

### 3. Практическое применение в ИБ
- **DNS-атаки:** Понимаю механизмы DNS Spoofing, DNS Tunneling и их влияние на безопасность.
- **Анализ трафика:** Могу анализировать DNS-запросы для выявления вредоносной активности (например, C2-коммуникации).
- **Настройка безопасности:** Знаю, как использовать DNSSEC и фильтрацию DNS для защиты сети.

## 🧠 Примеры из практики
- Использовал `nslookup` и `dig` для разрешения DNS-записей и анализа CNAME-алиасов.
- Изучал TXT-записи для проверки настроек SPF и DMARC.
- Анализировал TTL для понимания времени кэширования и возможных задержек.

## 🔧 Инструменты
- `nslookup`, `dig`
- Базовое понимание Wireshark (анализ DNS-трафика)
