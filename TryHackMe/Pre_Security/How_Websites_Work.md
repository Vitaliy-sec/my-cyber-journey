# TryHackMe: How Websites Work

## 📌 Краткое описание
Пройден модуль, посвящённый архитектуре веб-приложений, их компонентам и базовым уязвимостям. Изучены фронтенд и бэкенд технологии, а также механизмы, лежащие
в основе веб-коммуникации. Понимание этих основ критично для анализа веб-приложений и выявления уязвимостей.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание веб-архитектуры
- **Фронтенд (Client-Side):** HTML, CSS, JavaScript.
- **Бэкенд (Server-Side):** Сервер, база данных, логика приложения.
- **Взаимодействие:** Браузер отправляет запрос → сервер обрабатывает → браузер отображает.

### 2. HTML (язык разметки)
- **Структура:** `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.
- **Основные теги:** `<h1>`, `<p>`, `<a>`, `<img>`, `<div>`, `<button>`.
- **Атрибуты:** `id`, `class`, `src`, `href`.
- **Разница между `.jpg` и `.png`:** Понимаю, когда использовать каждый формат.

### 3. JavaScript (интерактивность)
- **DOM-манипуляции:** Понимаю, как JavaScript изменяет содержимое страницы.
- **События:** `onclick`, `onhover`, `onload`.
- **Взаимодействие с HTML:** Понимаю, как JS работает с элементами через `document.getElementById`.

### 4. Уязвимости и безопасность
- **Экспозиция чувствительных данных:** Умею находить в исходном коде пароли, API-ключи, скрытые ссылки.
- **HTML-инъекция:** Понимаю, как нефильтрованный пользовательский ввод может привести к выполнению HTML и JavaScript.
- **XSS (Cross-Site Scripting):** Понимаю, как инъекция JS может привести к краже сессий, фишингу и другим атакам.
- **CSRF (Cross-Site Request Forgery):** Понимаю, как злоумышленник может заставить пользователя выполнить нежелательные действия.

### 5. Практические навыки
- **Анализ исходного кода:** Умею искать чувствительные данные в HTML, CSS и JavaScript.
- **Тестирование HTML-инъекций:** Могу проверять поля ввода на наличие уязвимостей.
- **Использование DevTools:** Умею анализировать запросы и ответы через инструменты разработчика.

## 🧠 Примеры из практики
- Нашёл скрытые комментарии в HTML с тестовыми учётными данными.
- Вставил HTML-код через поле ввода для проверки фильтрации.
- Анализировал JavaScript для поиска API-ключей и токенов.
