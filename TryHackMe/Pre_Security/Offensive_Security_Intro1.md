# TryHackMe: Offensive Security Intro (Введение в наступательную безопасность)

## 📌 Краткое описание
Пройден вводный модуль по наступательной безопасности (Offensive Security). Изучены ключевые термины (Red Teaming, Penetration Testing, Scope, Vulnerability, Exploit). На практике применён инструмент **Gobuster** для автоматизированного поиска скрытых директорий на веб-сервере.

## 🧠 Ключевые термины
- **Red Teaming:** Имитация реальной атаки для проверки защиты.
- **Penetration Testing:** Авторизованная оценка безопасности с поиском уязвимостей.
- **Scope (Область действия):** Границы того, что разрешено проверять.
- **Vulnerability (Уязвимость):** Слабость в системе, которую можно использовать.
- **Exploit (Эксплойт):** Метод использования уязвимости.

## 🛠️ Практические навыки
- **Ручной поиск скрытых страниц:** Проверка типовых URL (`/admin`, `/login`, `/sitemap`, `/mail`).
- **Автоматизированный поиск:** Использование `gobuster` для перебора директорий по словарю.
