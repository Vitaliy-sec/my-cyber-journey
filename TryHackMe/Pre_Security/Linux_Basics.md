# TryHackMe: Linux Basics

## 📌 Краткое описание
Пройден модуль, посвящённый основам операционной системы Linux. Изучены навигация по файловой системе, поиск файлов, проверка системной информации, чтение конфигурационных файлов и работа в командной строке. Эти навыки являются фундаментом для анализа систем, поиска уязвимостей и выполнения задач по обеспечению безопасности.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Навигация по файловой системе
- Уверенное перемещение по каталогам (`cd`, `ls`, `pwd`).
- Понимание структуры файловой системы Linux.

### 2. Поиск файлов
- Использование `find` для поиска файлов по имени, размеру, типу.
- Использование `grep` для поиска текста внутри файлов.

### 3. Проверка системной информации
- Просмотр информации о системе (`uname`, `hostname`, `df`, `free`).
- Мониторинг процессов (`ps`, `top`).

### 4. Чтение конфигурационных файлов
- Анализ системных конфигураций (`/etc/passwd`, `/etc/shadow`, `/etc/ssh/sshd_config`).
- Понимание формата и назначения ключевых конфигурационных файлов.

### 5. Работа в командной строке
- Выполнение задач в среде Linux.
- Использование команд для управления системой.

### 6. Связь с безопасностью (практическое применение)

| Навык | Как используется в безопасности | Пример |
| :--- | :--- | :--- |
| **Навигация** | Обнаружение подозрительных файлов и директорий. | Найти скрытые каталоги с вредоносным ПО. |
| **Поиск файлов** | Выявление аномалий в файловой системе. | `find / -name "*.php" -mtime -1` — найти недавно изменённые PHP-файлы. |
| **Чтение конфигураций** | Проверка настроек безопасности. | Проверить `sshd_config` на наличие слабых параметров. |
| **Системная информация** | Обнаружение вредоносных процессов и нехватки ресурсов. | `top` — найти процессы с высокой загрузкой CPU. |
