# TryHackMe: Offensive Security Intro (Наступательная безопасность)

## 📌 Краткое описание
Пройден модуль, посвящённый основам этичного хакинга (Red Teaming). Изучена терминология, методология и границы дозволенного (Scope). На практике выполнены задачи по разведке (Enumeration) и эксплуатации уязвимостей веб-приложения с использованием автоматизированных инструментов.

## 🛠️ Ключевые навыки и инструменты

### 1. Разведка (Enumeration)
- **Ручной поиск:** Проверка типовых URL (`/login`, `/admin`, `/sitemap`).
- **Автоматизация (Gobuster):** Перебор директорий по словарю для поиска скрытых страниц.

  gobuster dir --url http://www.onlineshop.thm/ -w /usr/share/wordlists/dirbuster/directory-list.txt
