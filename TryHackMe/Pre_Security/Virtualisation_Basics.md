# TryHackMe: Virtualisation Basics

## 📌 Краткое описание
Пройден модуль, посвящённый основам виртуализации и контейнеризации. Изучены принципы работы гипервизоров, виртуальных машин и контейнеров, а также их роль в современной ИТ-инфраструктуре. Понимание этих технологий критично для анализа и проектирования безопасных, масштабируемых и экономически эффективных систем.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Понимание виртуализации
- **Виртуализация:** Один физический сервер → несколько виртуальных сред.
- **Гипервизор:** Управляет распределением ресурсов (Type 1: bare-metal, Type 2: host-based).
- **Виртуальная машина (VM):** Полноценный компьютер внутри другого.

### 2. Понимание контейнеризации
- **Контейнер:** Лёгкая изоляция для одного приложения.
- **Контейнер-образ:** Шаблон для создания контейнеров.
- **Разница с VM:** Контейнеры используют ядро хоста, быстрее запускаются, но слабее изолированы.

### 3. Связь с безопасностью (практическое применение)
| Концепция | Преимущества для безопасности | Риски |
| :--- | :--- | :--- |
| **Изоляция VM** | Компрометация одной VM не влияет на другие. | Гипервизор — единая точка отказа. |
| **Контейнеры** | Быстрое обновление, минимальная поверхность атаки. | Слабее изоляция (общее ядро). |
| **Сетевые порты** | Контроль доступа к сервисам. | Неправильная настройка → уязвимости. |

### 4. Преимущества виртуализации для бизнеса
- **Экономия средств:** Меньше физических серверов.
- **Масштабируемость:** Быстрое добавление ресурсов.
- **Гибкость:** Быстрое развертывание и тестирование.
- **Портативность:** Миграция VM между серверами.
