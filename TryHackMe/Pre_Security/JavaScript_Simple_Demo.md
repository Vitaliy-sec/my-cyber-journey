# TryHackMe: JavaScript Simple Demo

## 📌 Краткое описание
Пройден модуль, посвящённый основам программирования на JavaScript. На практике разобрана программа «Угадай число», включающая работу с переменными, условными операторами и циклом `while`. Изучены особенности ввода-вывода в Node.js, а также проведено сравнение с Python. Понимание JavaScript критично для анализа веб-уязвимостей (XSS) и разработки клиентских скриптов.

## 🛠️ Ключевые навыки, полученные в модуле

### 1. Переменные и константы
- **`let`** — переменная (значение может меняться).
- **`const`** — константа (значение не меняется).
- **`parseInt(text, 10)`** — преобразование строки в число.

### 2. Условные операторы (if / else if / else)
- **Синтаксис:** `if (условие) { ... } else if (условие) { ... } else { ... }`.
- **Логические операторы:** `||` (или), `&&` (и), `!` (не).
- **Операторы сравнения:** `<`, `>`, `!==`, `==`, `===`.

### 3. Циклы (while)
- **Синтаксис:** `while (условие) { ... }`.
- **Логика:** повторение блока кода, пока условие истинно.
- **Применение:** игра продолжается, пока пользователь не угадает число.

### 4. Ввод-вывод в Node.js
| Функция | Назначение | Пример |
| :--- | :--- | :--- |
| **`console.log()`** | Вывод текста на экран. | `console.log("Hello")` |
| **`rl.question()`** | Ввод данных от пользователя. | `await rl.question("Enter: ")` |
| **`rl.close()`** | Закрытие интерфейса. | `rl.close()` |

### 5. Сравнение Python и JavaScript
| Что делаем | Python | JavaScript |
| :--- | :--- | :--- |
| **Переменная** | `tries = 0` | `let tries = 0;` |
| **Константа** | нет | `const secret = 12;` |
| **Не равно** | `!=` | `!==` |
| **Цикл** | `while guess != secret:` | `while (guess !== secret) {` |
| **Вывод** | `print("...")` | `console.log("...")` |

### 6. Связь с безопасностью (практическое применение)
| Концепция | Как используется в ИБ | Пример |
