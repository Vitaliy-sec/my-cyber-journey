# TryHackMe: Linux Fundamentals Part 2

## 📌 Краткое описание
Пройден модуль, посвящённый углублённому изучению файловой системы Linux, управлению файлами и правами доступа. Освоены практические навыки навигации, создания, копирования и удаления файлов, а также переключения между пользователями.

## 🛠️ Ключевые навыки и команды

### 1. Управление файлами и папками
- **`touch`** — создание пустого файла.
- **`mkdir`** — создание папки (включая вложенные: `mkdir -p Documents/Homework`).
- **`cp`** — копирование файлов (`cp note Documents`).
- **`mv`** — перемещение или переименование файлов/папок.
- **`rm`** — удаление файлов (`rm -R` для папок).

### 2. Понимание структуры файловой системы
- **`/`** — корень (root).
- **`/etc`** — системные и конфигурационные файлы (например, `sudoers`).
- **`/var`** — переменные данные, логи (`/var/log`).
- **`/root`** — домашняя папка суперпользователя (root).
- **`/tmp`** — временные файлы (очищается при перезагрузке, доступен всем).

### 3. Права доступа и пользователи
- **`ls -l`** — просмотр прав доступа (чтение `r`, запись `w`, выполнение `x` для владельца, группы и остальных).
- **`su -l <user>`** — переключение на другого пользователя с полным окружением (например, `su -l user2`).
- **Понимание:** Владелец файла имеет одни права, группа — другие, остальные — третьи. Это позволяет гибко настраивать доступ.
