# TryHackMe: Windows Fundamentals 1

## 📌 Краткое описание
Пройден вводный модуль по операционной системе Windows. Изучены интерфейс, файловая система NTFS, управление пользователями, механизм UAC и базовые инструменты мониторинга.

## 🛠️ Ключевые навыки и знания

### 1. Интерфейс и навигация
- Рабочий стол, панель задач, меню «Пуск».
- Настройки Windows и Панель управления.

### 2. Файловая система (NTFS)
- **NTFS:** Поддержка больших файлов, журналирование, права доступа, шифрование (EFS).
- **Папка Windows:** Переменная `%windir%` указывает на системную папку.
- **System32:** Критически важные системные файлы (удаление недопустимо).

### 3. Пользователи и права
- **Типы аккаунтов:** Администратор и Стандартный пользователь.
- **Инструменты:** `lusrmgr.msc` (Локальные пользователи и группы), Настройки → Другие пользователи.
- **Профили:** Папки пользователей в `C:\Users`.

### 4. Безопасность и мониторинг
- **UAC (User Account Control):** Запрос подтверждения при попытке изменить систему.
- **Диспетчер задач (Task Manager):** Мониторинг процессов, производительности, автозагрузки (открывается через `Ctrl + Shift + Esc`).

## 🛡️ Связь с безопасностью
- Понимаю разницу между администратором и обычным пользователем.
- Знаю, как работает UAC и зачем он нужен (защита от несанкционированных изменений).
- Умею анализировать запущенные процессы в Диспетчере задач.
