# TryHackMe: Linux Fundamentals Part 3

## 📌 Краткое описание
Завершающий модуль по основам Linux. Освоены продвинутые утилиты для работы с файлами, управление процессами, планирование задач (Cron), работа с пакетами (APT) и анализ логов.

## 🛠️ Ключевые навыки и инструменты

### 1. Передача файлов и веб-сервер
- **`wget`** — скачивание файлов из интернета.
- **`scp`** — безопасное копирование файлов между компьютерами по SSH.
- **`python3 -m http.server`** — запуск простого веб-сервера для передачи файлов.

### 2. Управление процессами
- **`ps`**, **`ps aux`** — просмотр запущенных процессов.
- **`top`** — мониторинг в реальном времени.
- **`kill`** — завершение процессов (сигналы `SIGTERM`, `SIGKILL`, `SIGSTOP`).
- **Фоновый режим:** запуск команд с `&`, приостановка через `Ctrl+Z`, возврат через `fg`.

### 3. Планирование задач (Cron)
- **`crontab -e`** — редактирование расписания.
- **`crontab -l`** — просмотр задач.
- **Формат:** `МИН ЧАС ДОМ МЕС ДЕНЬ_НЕДЕЛИ КОМАНДА`.
- **`@reboot`** — запуск команды при загрузке системы.

### 4. Управление пакетами (APT)
- **`apt update`** — обновление списков пакетов.
- **`apt install`** / **`apt remove`** — установка и удаление программ.
- **Добавление репозиториев:** работа с ключами GPG и файлами `/etc/apt/sources.list.d/`.

### 5. Анализ логов (Logs)
- **`/var/log/`** — основная директория для логов.
- **`/var/log/apache2/access.log`** — анализ веб-трафика (IP, запрошенные файлы).
- **Права доступа:** использование `su` для чтения системных логов.

- Понимаю принципы работы Cron (злоумышленники используют его для закрепления в системе).
- Знаю, как работают пакетные менеджеры (риск подмены репозиториев).
