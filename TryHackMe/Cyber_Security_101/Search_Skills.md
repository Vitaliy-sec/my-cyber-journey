# TryHackMe: Search Skills (Навыки поиска информации и OSINT)

## 📌 Краткое описание
Пройден модуль, посвящённый методам поиска информации (OSINT) и работе с базами данных уязвимостей. Изучены инструменты для разведки, проверки файлов и поиска технической документации, что критически важно для анализа безопасности и реагирования на инциденты.

## 🛠️ Ключевые навыки и инструменты

### 1. Shodan (Разведка интернет-устройств)
- Понимаю, что Shodan индексирует сетевые устройства (IoT, серверы, SCADA), а не веб-страницы.
- Умею использовать фильтры для сужения поиска: `country:`, `port:`, `org:`, `hostname:`.
- На практике искал уязвимые версии веб-серверов (например, `apache 2.4.1`).

### 2. VirusTotal (Анализ файлов и ссылок)
- Знаю, как проверить подозрительный файл или URL через 70+ антивирусных движков.
- Понимаю, как интерпретировать результаты (количество детекций) для оценки риска.

### 3. CVE и CVSS (База уязвимостей)
- Понимаю формат идентификаторов `CVE-ГОД-НОМЕР` (например, CVE-2021-44228).
- Знаю, как работает система оценки **CVSS** (0-10) для приоритизации уязвимостей.
- Умею связывать CVE с публичными PoC (Proof of Concept) на GitHub.

### 4. Man Pages (Официальная документация)
- Использую команду `man <команда>` для получения справки по инструментам Linux.
- Понимаю важность официальной документации как первого источника информации.

### 5. GitHub как OSINT-инструмент
- Умею искать PoC-коды и технические отчеты по новым уязвимостям.
- Понимаю риски: проверяю код перед запуском (возможны вредоносные репозитории).

## 🛡️ Связь с безопасностью
- Владею базовыми навыками OSINT для поиска информации об уязвимостях.
- Умею проверять файлы на вредоносность и находить техническую документацию.
- Понимаю, как использовать эти инструменты в легальных рамках для тестирования безопасности.
