# Отчёт по комнате: TryHackMe Windows Fundamentals 1

## 📌 Контекст и цель
**Платформа:** TryHackMe
**Путь:** Cyber Security 101
**Сложность:** Начальный (Easy)
**Цель:** Изучить базовые компоненты ОС Windows, файловую систему NTFS, управление пользователями и механизмы безопасности (UAC).

## 🛠️ Инструменты и методы
В ходе выполнения комнаты использовались:
*   **Графический интерфейс Windows:** Настройки, Панель управления, Проводник.
*   **Утилиты командной строки:** `lusrmgr.msc` (Локальные пользователи и группы), Диспетчер задач.
*   **Анализ файловой системы:** Изучение прав доступа NTFS, переменной `%windir%`.

## 🔍 Ключевые находки и анализ

### 1. Файловая система NTFS
*   **Что обнаружено:** Windows использует NTFS, которая поддерживает журналирование, права доступа и шифрование (EFS).
*   **Значимость для безопасности:** В отличие от FAT32, NTFS позволяет разграничивать доступ к файлам на уровне пользователей и групп, что является основой защиты данных. Понимание прав NTFS критично для предотвращения несанкционированного доступа.

### 2. Управление пользователями
*   **Что обнаружено:** С помощью `lusrmgr.msc` были идентифицированы учетные записи. Обнаружен пользователь `tryhackmebilly` с полным именем `TRY HACK ME`, который состоит в группах `Users` и `Remote Desktop Users`. Встроенная гостевая запись — `Guest`.
*   **Значимость для безопасности:** Аудит учетных записей и их членства в группах — первый шаг в оценке безопасности системы. Наличие пользователя в группе `Remote Desktop Users` увеличивает поверхность атаки (возможность удаленного подключения).

### 3. Контроль учетных записей (UAC)
*   **Что обнаружено:** UAC (User Account Control) запрашивает подтверждение при попытке выполнить действие, требующее прав администратора.
*   **Значимость для безопасности:** UAC — это ключевой механизм защиты от несанкционированных изменений системы. Даже если пользователь является администратором, его сессия работает с ограниченными правами, что снижает риск заражения вредоносным ПО.

## 💡 Выводы и рекомендации (для гипотетической системы)
*   **Рекомендация 1 (Учетные записи):** Регулярно проводить аудит пользователей и их групп. Удалять неиспользуемые учетные записи (например, если `tryhackmebilly` не нужен, его стоит отключить).
*   **Рекомендация 2 (UAC):** Убедиться, что UAC включен и настроен на максимальный уровень уведомлений для всех пользователей, включая администраторов.
*   **Рекомендация 3 (Файловая система):** Проверить права доступа к критическим папкам (например, `C:\Windows\System32`). Убедиться, что обычные пользователи не имеют прав на запись в системные директории.
