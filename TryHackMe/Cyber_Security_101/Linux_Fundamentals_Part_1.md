# TryHackMe: Linux Fundamentals Part 3

## 📌 Краткое описание
Пройден заключительный модуль по основам Linux. Освоены продвинутые команды для поиска информации в системе, работы с текстом, а также операторы перенаправления вывода (redirection) и объединения команд.

## 🛠️ Ключевые навыки и команды

### 1. Поиск информации
- **`find`** — поиск файлов по имени, размеру, типу.
- **`grep`** — поиск текста внутри файлов.
- **`wc`** — подсчет слов, строк и символов в файле.

### 2. Операторы перенаправления и объединения
- **`&`** — запуск команды в фоновом режиме.
- **`&&`** — выполнение следующей команды только после успешного завершения предыдущей.
- **`>`** — перенаправление вывода в файл (перезапись).
- **`>>`** — добавление вывода в конец файла.

### 3. Работа с текстом
- **`cut`**, **`sort`**, **`uniq`** — обработка и фильтрация текста (из прошлых частей).
- **`nano`** / **`vim`** — базовые текстовые редакторы.

- Знаю, как объединять команды для автоматизации рутинных задач.
